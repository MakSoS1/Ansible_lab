# AIOS Hackathon — Track 2

Очищенный комплект исходных материалов, моделей месторождения и расшифровок лекций для проектирования масштабируемой многоагентной системы управления фондом скважин.

## Состав

- `materials/` — техническое задание, методики ЧДД, презентации, контрольные расчёты и исходные архивы Model Y / Model Z;
- `recordings/` — три исходные WEBM-записи лекций, хранящиеся через Git LFS;
- `transcripts/cleaned/` — читаемые расшифровки с тайм-кодами;
- `transcripts/raw/` — TXT, SRT, VTT, TSV и JSON, полученные Whisper;
- `manifests/SHA256SUMS` — контрольные суммы опубликованных файлов;
- `manifests/source-inventory.csv` — полный перечень решений о публикации и исключении.

## Конфиденциальность

Из комплекта исключены четыре документа со списками команд, ФИО, ролями и Telegram-идентификаторами участников. Причины перечислены в [EXCLUDED_PERSONAL_DATA.md](EXCLUDED_PERSONAL_DATA.md). Лекции выборочно проверены по кадрам: в публикуемых фрагментах отображаются слайды и докладчики, а не списки участников.

## Назначение приватного Hugging Face Dataset

Этот же очищенный комплект публикуется в приватный датасет `MakSoS1/aios-track2-runs`. В дальнейшем GitHub Actions должен добавлять туда сценарии OPM Flow, конфигурации запусков, метрики, контрольные расписания и веса моделей. Текущая загрузка не запускает симуляцию или обучение.

## Важная неоднозначность ЧДД

Исправленная методика задаёт начало экономического расчёта для трека 2 с `01.01.2007`. Контрольная таблица Model Z использует дисконтирование от 1991 года. До официального уточнения реализация должна считать вариант с 2007 года контрактным, а обе контрольные траектории — отдельными regression fixtures.
