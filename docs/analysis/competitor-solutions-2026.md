# AIOS Track 2 — актуальные решения конкурентов (2024–2026)

Сводка только по работам, которые сейчас задают практику well-control + surrogate. Их выводы использованы в bake-off из пяти полностью реализованных контроллеров.

## Что делают сильные решения сейчас

1. **GNN-LSTM / GraphSAGE + LSTM (SPE 215842, 2024)**  
   Скважины — вершины, пары нагнетательная–добывающая — рёбра, LSTM разворачивает граф во времени. На поле со 189 скважинами ошибка дебита нефти ~4%, ускорение >1000×, оптимизация закачки через PSO. Прямой аналог нашего `graph_ensemble`.

2. **Transformer-LSTM + генетическая/TOPSIS оптимизация (Zhang–Gong–Huang, EAGE APAC 2025)**  
   Гибрид LSTM (локальная динамика) и Transformer (длинные зависимости) для послойной закачки. Ошибки валидации ~0.5–1% по нефти и обводнённости, затем многокритериальный поиск. Это семейство нашего `tcn_cem` (каузальный TCN как устойчивый родственник LSTM/Transformer без тяжёлого attention на коротком горизонте).

3. **Transformer-LSTM + совместная оптимизация расписания (Energy 2025, Wu et al.)**  
   Суррогат итеративно дообучается во время оптимизации (active learning). Co-optimization расписания даёт +12–13% NPV и режет время поиска ~70%. У нас это `linear_cem` / `graph_cma` + promotion/active learning.

4. **PPO closed-loop reservoir management (Nasir & Durlofsky 2022–2023)**  
   Policy-gradient на быстрой модели, +15–33% NPV vs robust optimization, меньше прогонов симулятора. Лекция 2 хакатона прямо ссылается на это. Наш `mappo` — CTDE-challenger по кластерам, не агент-на-скважину.

5. **Инженерный waterflood control (лекция 3 / Татнефть 2026)**  
   Компенсация, лаги закачка→добыча, резка высоких WCT, запрет локальной жадности. Это `heuristic`: без обучения, но с тем же Constraint Guard. Нужен как нижняя планка и генератор кандидатов.

## Чего из литературы мы сознательно не берём в спринт

- PINN/FNO на сетке 91×102×59 — слишком дорого для M1 runner и 7 дней.
- Один RL-агент на каждую скважину — лекция 2: non-stationarity и credit assignment.
- Заявленный NPV с суррогата — дисквалификация по регламенту.

## Как сравниваем не одной метрикой

| Метрика | Зачем |
|---|---|
| Подтверждённый NPV (proxy сейчас, OPM при наличии `flow`) | Единственный критерий победителя |
| Spearman ранжирования NPV | Суррогат может врать абсолютно, но обязан сортировать гипотезы |
| MAE/NRMSE нефти, жидкости, закачки, BHP | Качество динамики |
| Калибровка uncertainty / OOD | Нельзя выпускать экстраполяцию без promotion |
| Число SHUT/OPEN и переводов | События ЧДД (1 и 5 млн ₽) |
| Нарушения WLPR≤500 | Hard gate |
| Latency | Трек 2 — масштаб и скорость |
| MARL lower bootstrap bound | Challenger допускается только если устойчиво бьёт CEM |
