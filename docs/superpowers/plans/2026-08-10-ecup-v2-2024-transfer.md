# E-CUP v2 2024-Transfer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a complete v2 submission that independently transfers the strongest public E-CUP 2024 product-matching ideas to 2026 data, adds a GPU-trained compact pair reranker, and improves the fixed item-disjoint Macro AP while remaining organizer-compatible.

**Architecture:** Keep v1 as an immutable anchor. Build a deterministic data-quality/augmentation layer, extend structured product features, add confidence-weighted weak labels and hard-negative mining, then train a compact transformer pair classifier on Lightning AI. Select a structured/neural blend on an item-disjoint calibration split and package all inference artifacts offline.

**Tech Stack:** Python 3.11/3.12, pandas, numpy, scikit-learn, PyTorch, transformers, sentence-transformers, Hugging Face Hub, Lightning SDK, GitHub Actions, Docker organizer image.

## Global Constraints

- Work only on branch `ecup-matching-2026`; do not modify or merge `main`.
- Keep the fixed v1 item-disjoint validation unchanged for headline comparisons.
- Metric is unweighted macro mean of per-category `average_precision_score` across 20 categories.
- Raw competition parquet, trained weights, submission ZIPs, DBs and credentials remain out of public Git.
- Lightning credentials and `HF_TOKEN` must never be printed, committed or embedded in workflow YAML.
- v2 final inference must run offline in `odsai/ecup26-matching-baseline:1.0` and emit exactly `id1,id2,predict`.
- Any current-participant solution copying is prohibited; only general public 2024 methods are reimplemented independently.
- Final v2 is accepted as the new best only if fixed-validation Macro AP exceeds `0.49616548946964434`.
