# E-CUP v9 Compact Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and publish a compact v9 submission that preserves validated behavior and passes an organizer-like end-to-end runtime gate including ZIP extraction.

**Architecture:** Audit the immutable v9 keeper first, then construct a compact archive by retaining only runtime-reachable artifacts. Verify original-vs-compact predictions on the same fixture, measure full extraction+inference wall time on the RTX 2060 SUPER, and publish only the exact gated bytes.

**Tech Stack:** Python 3, `zipfile`, NumPy/Pandas, PyTorch/Transformers, Docker organizer image, GitHub Actions, private self-hosted RTX 2060 SUPER runner, Hugging Face Hub.
