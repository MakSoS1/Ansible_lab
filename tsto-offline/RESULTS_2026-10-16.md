## Root-cause observations

- The native Scorpio client reached `/mh/gameplayconfig`, `/gameassets/dlc/DLCIndex.zip`,
  the real `DLCIndex-v4_69_UNTROUBLEDVASES_PATCH2...`, and
  `/proxy/identity/pids//personas`, all HTTP 200 in the bounded test.
  Previous path-routing failures have been corrected.
- The **actual first fatal game error message**, extracted from the Android logcat
  in run 38873189010, is `ScorpioDLCIndex::AddPackageToDownload: DLC package failed
  to download 3 times; file: simpsons4:4_7_2r1_FEB2014_Takedown_c0ac9bee:Shadows-100-r146180-0D2B882C.zip`.
- At the same phase other HTTP 404 content groups were
  `4_67_CharityCase_LXJ0SRBNF13A`,
  `4_4_0r2_Videos`,
  `4_18_XMAS2015_Takedown_WQBO2OV3G5ZU`,
  `4_42_HeroesOfSpringfield_5CRHS6IO8JG3`.
  Their **archive sizes** in the prior complete restore manifest are respectively
  100,313,124; 1,310,376,538; 427,616,205; and 78,591,282 bytes; the first
  Shadows archive is 718,001 bytes. Download only in a strict second-wave test.
- Native renderer can show real Simpsons error/UI screens on native ARM64 Android 15,
  even when game content is incomplete. A `SIGABRT` recorded in that bounded-run
  log is from Android's **Bluetooth service**, **not the Scorpio game process**.
  Do not confuse with older Scorpio GLThread crashes from other CI configurations.
- The old complete 31 GB corpus still references **3,968 missing files** overall,
  of which **790** are among approximate RU/EN candidates. Do not assert archive
  completeness based solely on 151/151 index manifests.
- The logging middleware previously monitored only `/gameassets/` and missed
  the game's original-length padded address `/pppp.../gameassets/`; now patched
  in `transfer_audit.py` and covered by tests. It measures actual yielded
  bytes, response length, Range, and premature transfer aborts. Changes after
  run 38874422985 will require a new small CI job for verification of real
  network stream metrics.

## Strict release acceptance remains UNSATISFIED

1. Real Springfield scene with interactive objects and completed tutorial — not proven.
2. Genuine saved-city load/POST and persistence after process restart — not proven.
3. Fresh cold-start without any external server or ADB reverse — not proven.
4. Android **16**, Pixel 10 (including 16 KiB memory pages) — not tested
   on an actual compatible runtime.
5. Fully self-contained, appropriately licensed game assets — unavailable.
   The 31.4 GB archive cannot be directly placed inside one conventional APK.
6. Do not distribute diagnostic APK as a complete offline game.

## Reusable triage

`tsto-offline/build/report_bootstrap_gaps.py` reads **logs and archive metadata**
without downloading content. It extracts failed `/gameassets/` HTTP responses,
native Scorpio package failures, and proposes bounded archive group selections.
Continue testing smallest real missing groups before any full archive run.

Commit history in this branch documents the bounded-index, archive-bootstrap,
stream-audit and HTTP 502 retry improvements.
